# PITURE-WORKFLOW

ComfyProductPipeline 商品图工作流的完整项目备份。

## 下载完整项目

请进入 [Releases](https://github.com/minner-965/PITURE-WORKFLOW/releases)，下载完整备份的所有分卷、文件清单、SHA256SUMS 和恢复说明。

备份包含项目目录内的代码、配置、工作流、文档、输入素材、生成图片、历史交付、缓存与临时文件，并保留符号链接。完整内容以 Release 中的文件清单和校验报告为准。

**GitHub 的 Code → Download ZIP 和 Release 自动生成的 Source code 文件只包含本说明，不是完整备份。请下载备份附件。**

## 恢复

将同一次备份的所有附件下载到一个文件夹，按该 Release 附带的中文恢复说明校验并合并分卷，然后解压到新目录。保留备份原件，避免覆盖现有项目。

## 环境边界

本备份以 `ComfyProductPipeline` 项目目录为边界。项目内符号链接会原样保存；项目目录外的 ComfyUI 安装、模型权重及系统运行时需单独准备。当前备份不是整台电脑的系统镜像。
